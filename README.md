# Mes Photos par Moi
Bienvenue sur "Mes Photos par Moi", un site web de galerie de photos conçu pour présenter des moments uniques capturés à travers le monde par Oriol, un photographe passionné.

# Fonctionnalités du site
Ce site est conçu pour être simple et intuitif, offrant les fonctionnalités suivantes :

1. Galerie d'images : Parcourez une collection de photos affichées de manière esthétique.

2. Filtrage par catégorie :

- Utilisez les boutons de filtre ("Tous", "Art", "Urbain", "Nature", "Événements", "Autre") pour afficher les photos par catégorie spécifique.

3. Fonction de recherche :

- Recherchez des photos en utilisant la barre de recherche. Vous pouvez taper des mots-clés qui correspondent au nom du fichier de l'image ou à sa description (alt text). La recherche s'applique en temps réel et fonctionne en combinaison avec les filtres de catégorie.

4. Affichage modal des images :

- Cliquez sur n'importe quelle miniature dans la galerie pour ouvrir un grand aperçu de l'image dans un popup central.

- Dans ce popup, l'image s'affiche entièrement, sans déformation, et est accompagnée  de sa description.

- Un bouton "X" (fermer) est disponible en haut à droite du popup pour le fermer et revenir à la galerie.

# Comment utiliser le site
- Naviguer dans la galerie : Faites défiler la page pour voir toutes les photos disponibles.

- Filtrer les photos : Cliquez sur les boutons de catégorie en haut de la section "Galeries" pour affiner votre sélection.

- Rechercher des photos : Utilisez la barre de recherche pour trouver des photos spécifiques par mots-clés.

- Voir une photo en grand : Cliquez sur la photo de votre choix dans la galerie.

- Fermer le popup : Cliquez sur le "X" en haut à droite du popup ou appuyez sur la touche Échap de votre clavier.
